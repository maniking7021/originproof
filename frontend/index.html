How it works

1 · Register — the file is hashed in your browser (SHA-256 + dHash). Only the hashes, a title and your address go on-chain.
2 · Verify — re-upload any file. An exact fingerprint match returns the original registration; otherwise the perceptual hash finds near-duplicates and reports a similarity %.
3 · Certificate — every registration gets a shareable certificate page with a QR code (#/cert/<sha256>).

Honest limits

Perceptual hash works on images and on sampled video frames; it is a similarity signal, not a legal proof of ownership. The AI-origin score is a metadata heuristic, not a certified detector — metadata can be stripped or forged, so a low score never proves a file is human-made. The invisible watermark survives re-saving but not aggressive recompression or cropping. The C2PA manifest is a sidecar JSON aligned to C2PA assertion labels — it is not a signed JUMBF box or a certified Content Credential (see README). A SHA-256 match proves the file is byte-identical to the registered one; a near-duplicate match proves visual similarity, not that the copy came from the original. Registration is first-come-first-served: whoever registers first holds the origin claim. Your file never leaves your device — hashing, fingerprinting and verification all run in your browser, and this app works offline once installed.
